# BRAVO API

Fastify API читает данные Supabase через Prisma и является единственной серверной точкой доступа сайта к базе.

```bash
npm run dev:api
```

По умолчанию сервер слушает `127.0.0.1:3001`. Настройки находятся в корневом `.env`:

```env
API_HOST="127.0.0.1"
API_PORT="3001"
APP_URL="http://localhost:3000"
```

Для нескольких разрешённых сайтов укажите `APP_URL` через запятую. Ошибки API возвращаются в едином формате `{ "error": { "code", "message" } }`.

Расчёт доступности учитывает длительность услуг, индивидуальные цены и длительности мастера, рабочие часы, перерывы, `time_off`, существующие записи, минимальное время до визита и горизонт бронирования. PostgreSQL exclusion constraint окончательно защищает одного мастера от пересекающихся подтверждённых записей.

Тесты:

```bash
npm run test:unit --workspace @barber/api
npm run test:race --workspace @barber/api
```
